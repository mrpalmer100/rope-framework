# Release notes (all versions)

Per-release snapshots, one file per version — **including the current release**.
Each is frozen: it records the corpus as it stood at that release, so its claim
counts and status figures are correct *for that release only*, and none is ever
edited after the fact. The newest file here corresponds to the current version
(see the top-level `README.md`, which links directly to it); it lives alongside
the older notes because it is the same kind of artifact — a fixed snapshot — not
because the current release is "past." Do not edit any of these to match the
current registry; that is what the living documents in `docs/` are for.

If you want the current state of the programme, read `docs/STATE_OF_THE_PROGRAMME.md`
and `docs/PROGRAMME_OVERVIEW.md`. If you want the running log, read the top-level
`CHANGELOG.md`. These files exist purely for provenance — to show what was claimed
when, and how the programme grew.
