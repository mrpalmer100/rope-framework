# Technical records (machine-facing)

Working records from the programme's construction: sector-closure notes, campaign
syntheses, sealed-commission audits, methodology and standing-rule statements, and
task prompts written for AI construction efforts. They exist for **provenance and
traceability** -- to show how results were reached and audited -- not as reading for
a newcomer.

If you are evaluating the programme, you want the human-facing docs one level up in
`docs/` (start with `STATE_OF_THE_PROGRAMME.md`, `PROGRAMME_OVERVIEW.md`, and
`EXTERNAL_REVIEW_PACKAGE.md`). These records are what you consult when you want to
trace a specific claim's history or audit a specific decision.
