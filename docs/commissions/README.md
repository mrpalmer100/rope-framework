# ABSOLUTE-SCALE CAMPAIGN: COMMISSION PACKAGE (2026-08-05)

Six commissions drafted following the Fable 5 review of the v2.3.x
absolute-mass work (FND-MATTER-055 through 060, the M-point chain, and the
gravity-sector scale claims). House protocol throughout: pre-committed
bars, seals where a target could contaminate a construction, stopping
rules fixed before any sequence runs, negatives registered as keepers.

## Recommended order

TIER 1: consistency crises (cheap, decidable, potentially reorganizing)
- COMMISSION_A_dispersion_coefficient.md
  Reconciles FND-REL-002 (exact emergent LI) with FND-MATTER-005's
  claimed (ka)^2 measurement route. Either the route is void or the
  a = 6.0e-17 m scale faces astrophysical dispersion bounds.
- COMMISSION_B_two_lattice_reconciliation.md
  The M-point mesh (6.0e-17 m) vs the GRV-075/095 Planck selection
  (8 l_P): same lattice (contradiction; FND-MATTER-049 reopens) or two

TIER 2: the lambda near-miss, attacked at its unaudited links
- COMMISSION_C_scattering_casimir.md
  Replaces the displaced-fraction ANSATZ (never audited by the seals)
  with the scattering-theory zero-point computation. Two-session seal.
- COMMISSION_D_anisotropic_family_count.md
  Per-family displaced geometry (parallel vs perpendicular incidence);
  varies the isotropy assumption while C varies the ansatz. Independent
  by bar; informal factor-multiplication forbidden.
- COMMISSION_E_target_side_audit.md
  The audit FND-MATTER-060 itself named: does the MATTER055 target
  convert through T0/Sigma? Mechanism sealed OUT, per 060's asymmetry.

TIER 3: the identity program (parallelizable)
- COMMISSION_F_electron_identity.md
  Four sub-commissions: threshold star, winding terminus, collective
  gap, and the ratio-first m_p/m_e target. Circularity-first bars
  throughout; the prize in each is converting the one spent calibration
  into a consistency test.

## Cross-commission rules
- No session runs more than one commission per arc.
- A and B may run same-day; their subjects are disjoint.
- C, D, E may run in parallel with sealed sessions; their verdicts must
  be registered before any combined construction is attempted, and a
  combined construction is a new commission, not an assembly.
- Calibration count remains ONE unless F1-F4 convert it to a check.
