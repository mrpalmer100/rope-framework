## The question
FND-MATTER-056 built lambda from the ansatz "zero-point shift = displaced
area fraction," lambda = pi (r/a)^2, and FND-MATTER-058 multiplied by the
forced polarization factor 2, landing at 2.08x against a 2.00x bar. The
two-seal campaign (059/060) audited the FACTORS. It never audited the
ANSATZ. The displaced-fraction approximation is a leading-order guess, not
a theorem; the correct object for a rigid cylindrical inclusion in a
wave-bearing medium is the scattering-theory (phase-shift / Krein-formula)
zero-point energy, whose dilute-limit coefficient for cylinders is known to
differ from the naive volume fraction by factors of exactly the size the
gap needs, in either direction.

Task: pose the mode problem with the inclusion as a boundary condition
derived from the corpus's own contact law (or Dirichlet if the contact law
forces it), compute the zero-point shift from the scattering phase shifts,
and extract the replacement for pi (r/a)^2 from first principles.

## Stopping rule

coefficient lands inside the bar, it is registered as the sector's first
derived lever, at whatever grade the boundary-condition provenance
supports (B1). If it misses, the dilute-Casimir family is registered as
CLOSED for lambda, which is itself a keeper: it would exclude the entire
"zero-point displacement" class and force the suppression question
elsewhere.
