# COMMISSION B: THE TWO-LATTICE PROBLEM

## The question
The corpus now carries two pins on a microscopic length, roughly 18 orders
of magnitude apart:

- Matter sector: the M-point calibration (FND-MATTER-044/049) fixes the
  mesh scale a = 6.0e-17 m, spending the one permitted calibration on m_e.
- Gravity sector: GRV-075/095 report that the observed G, through the
  induced-gravity coefficient of the measured weave band, selects
  a = 8 Planck lengths (~1.3e-34 m).

GRV-007 flagged that the gravitational cutoff a_grav need not equal the
mesh spacing. But the GRV-075 band is computed from the same weave Hessian
the matter sector lives on. The commission's question: are these the same
lattice or not, and either way, what claim states it?

## Why this matters
FND-MATTER-049 pre-registered its own reopening condition: "any independent
pin of the mesh disagreeing with the M-point beyond the zero-point band."
If the GRV-075 selection is a pin on the SAME a, that condition has fired
and the terminus reopens. If it is a pin on a DIFFERENT length, the corpus
is running two lattices and no claim currently says which modes belong to
which scale, which is a bookkeeping hole through which future double-counts
will walk.

## Pre-committed bars
- B1: trace, claim by claim, which registered quantities the GRV-075 band
  coefficient actually depends on. The verdict "same lattice" or "distinct
  lattice" must be read off the dependency graph, not asserted.
- B2: if distinct, the session must name BOTH lengths, state which
  registered claims use which, and flag every claim that uses "a"
  ambiguously. The output is a two-column allocation table, auditable line
  by line.
- B3: if same, FND-MATTER-049's reopening condition is declared FIRED and
  the conflict registered at full volume. No harmonizing language; an
  18-order disagreement is not a tension, it is a contradiction.
- B4: no new physics may be introduced to resolve the conflict within this
  commission. This is an audit, not a construction. Resolution mechanisms
  (if any are apparent) are NAMED as next-orders, not executed.

## Seal
Target-free by construction: the question "which lattice does this
coefficient depend on" is a dependency-graph fact, wrong wherever it lands.
Ask it first, before any discussion of which answer the corpus would
prefer. (This is the METHODOLOGY_target_free_questions.md rule applied to
an audit rather than a factor.)

## Stopping rule
One dependency trace, one allocation table or one fired-condition
registration. If the trace is genuinely ambiguous (the band coefficient's
scale dependence cannot be determined from registered claims), register the
ambiguity itself as the finding; do not resolve it by judgment.

## Registrable outcomes (all acceptable)
1. Distinct lattices: allocation table registered; every ambiguous "a"
   flagged; GRV-007's caveat upgraded from remark to structural claim.
2. Same lattice: FND-MATTER-049 reopened; the M-point vs Planck conflict
   registered as the corpus's sharpest open contradiction.
3. Undecidable from registered claims: registered as such, with the
   specific missing dependency named.
