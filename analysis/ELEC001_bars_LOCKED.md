# ELEC-001 — Stable localized electron-candidate search

## Question
Does the current literal curve-field mechanics support a finite, localized,
topologically charged excitation that survives generic perturbations and
relaxes to a common attractor?

This is a prerequisite test only. It does not identify the object with the
physical electron.

## Bars locked before data

1. **Topology:** each perturbed Hopf candidate finishes with `|Lk-1| < 0.15`.
2. **Dissipation:** total energy falls by more than 5% in every trial.
3. **Localization:** final combined RMS radius lies in `0.4 < R_rms < 2.0`.
4. **Attractor consistency:** final-radius coefficient of variation is below 15%.
5. **Control:** an initially unlinked pair remains `|Lk| < 0.15`.

## Result

| Bar | Result |
|---|---|
| B1 topology | PASS: `|Lk| = 0.984–0.992` |
| B2 energy descent | PASS: `40.9–43.3%` reduction |
| B3 localization | **FAIL:** `R_rms = 2.579–2.589`, above locked ceiling 2.0 |
| B4 common attractor | PASS: radius CV `0.15%` |
| B5 unlink control | PASS: `0.0000 → 0.0000` |

## Interpretation

The present curve relaxation preserves unit linking, dissipates energy, and
converges extremely reproducibly—but to an expanded attractor. It does not
reproduce the previously published sourced-field Hopf scale near `R*=0.84`
under generic perturbation. That discrepancy must be reconciled before this
configuration can be promoted as a localized electron candidate.

## Status

**Failed, kept as a finding.** The next productive step is not to assign spin,
mass, or magnetic moment. It is to unify the sourced-field energy functional
and the flexible-curve dynamics and determine which equilibrium, if either, is
a genuine solution of one common action.
