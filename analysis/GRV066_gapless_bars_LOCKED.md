# GRV-066 — Is the locking modulus zero? The constructive case. Locked bars

## Commission and stance
GRV-065 left ell^2 = gamma/kappa as the load-bearing unknown. This session
searches the corpus for what constrains it, and it does so CONSTRUCTIVELY: the
task is to find whether the framework supports a working gravitomagnetic sector,
not to find another obstruction. Negative findings will be reported if they
arise, but they are not the target.

## Locked bars
B1 IDENTIFY kappa PHYSICALLY: in micropolar elasticity the rotation-locking
   modulus is the coefficient of |phi - (1/2) curl u|^2 -- i.e. A MASS TERM for
   the relative rotation. State this precisely.
B2 WHAT DOES THE CORPUS SAY ABOUT MASS TERMS IN THIS MEDIUM? Report
   EM-RECON-012's gauge argument and FND-STRAND-002's measurement, and state
   what each does and does not establish for the relative rotation specifically.
B3 IF kappa = 0: derive the resulting equation and its far field. Does it match
   Lense-Thirring's 1/r^2 shift falloff?
B4 THE HONEST GAP: EM-RECON-012's argument forbids a mass term for u because u
   is gauge. eta = phi - (1/2) curl u is built from DERIVATIVES and is gauge
   invariant, so that argument does not automatically extend. State what would
   still be needed.
B5 NEW PREDICTIONS: if the gravitomagnetic sector is carried by a gapless twist
   mode, what does the framework predict that standard physics does not? Name
   candidates for future testing.
