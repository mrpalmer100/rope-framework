# ROPE-SOURCE-AUDIT-002 — Locked bars

## Question

Can an undriven, closed rope possess a stable static or persistent dynamical circulation that generates a derived, non-integer observable holonomy?

## Null hypothesis

Without imposed motion, torque, current, flux, pumping, or an explicit circulation constraint, the corpus supplies no stable nonzero circulation. Any protected phase supplied by existing topology is an integer multiple of 2 pi and is therefore Aharonov--Bohm trivial.

## Required bars for a positive result

1. **No external drive** — no prescribed angular velocity, translation, current, torque, source term, boundary pump, or imposed flux.
2. **Dynamical selection** — circulation follows from the existing action or energy rather than being an initial condition conserved by construction.
3. **Static/metastable viability** — a nonzero circulating state is a stable or metastable stationary solution, or is protected by a demonstrated invariant against relaxation.
4. **Derived source map** — the corpus derives the mapping from the rope variable to the probe phase q Phi / hbar.
5. **Non-integer holonomy** — the predicted observable phase is not in 2 pi Z.
6. **Magnitude** — the phase is large enough to produce a spectral response above the validated instrument uncertainty without tuning a free coefficient to a favorable value.
7. **Parameter determination** — no arbitrary fractional coupling, offset phase, or externally chosen flux is inserted to obtain the result.

Failure of any bar closes the physical AB branch under the current framework.
