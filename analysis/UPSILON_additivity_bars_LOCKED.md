# Commission UPSILON — the additivity stress-test: locked bars

*Locked 2026-08-10. FND-033 named additivity (T_tube = n T0) as the new
deepest load-bearer under the Sigma pinning and asked whether the 0.02%
closure already bounds its violation. This session stress-tests both the
closure and additivity itself.*

## Locked bars
B1 THE CLOSURE AUDITED FOR CIRCULARITY, first and unflinchingly: trace how
   n and T0 were each determined in the lattice chain. If T0 was DEFINED as
   T_tube/n (or n as T_tube/T0), then n T0 = T_tube is an identity and
   FND-033's item (c) was bookkeeping, not a bound -- in that case a second
   in-arc correction pointer is filed against FND-033 before anything else
   is computed. The commission does not get to soften this if it falls.
B2 THE VIOLATION PARAMETER: define delta = (T_tube - n T0)/(n T0), the
   fractional non-additive (inter-strand binding) contribution. Derive its
   form from registered geometry: delta ~ g_c * E_x/(T0 a), with E_x the
   FND-029 inter-strand energy scale and g_c the intra-tube contact-geometry
   prefactor (contacts per strand per length, in units of 1/a). State
   plainly whether g_c is registered anywhere; if not, it is OPEN and the
   corpus may not silently set it to 1.
B3 THE FND-029 CONFRONTATION: propagate the registered band
   E_x/(T0 a) in [0.019, 87] through B2. If the band cannot bound delta
   usefully from above, say so; if the floor implies a minimum delta under
   any registered g_c, say that too. Impact statement required: the pinned
   Sigma is Sigma_eff = Sigma_strand (1 + delta); state at what delta the
   band assignment (3.61-3.70e35) stops being a per-strand statement.
B4 THE EXTERNAL DISCRIMINATOR, derived before searching: under EXACT
   additivity plus Sigma-universality, tubes of different color
   representation obey R_rep/R_fund = sqrt(sigma_rep/sigma_fund) -- for the
   adjoint (Casimir 9/4) tube, R_adj/R_fund = 3/2 EXACTLY, since both tubes
   must sit at the SAME Sigma. A binding non-additivity that varies with
   packing breaks this. One literature pass for measured adjoint-vs-
   fundamental flux-tube WIDTH ratios (the Lisbon finite-T companion
   measured quark-adjoint tubes; conversion pre-paid by ELEC-086's mapping).
   Confrontation bands, pre-committed on rho_R = R_adj/R_fund:
   CONSISTENT within +/-10% of 1.5; TENSION 10-25%; BROKEN > 25% (additivity
   or Sigma-universality wounded, delta-difference quantified). If no usable
   width ratio exists in reach, the discriminator is registered ARMED, the
   OMICRON pattern, with the conversion and bands locked here.
B5 HONESTY: sigma_adj itself must show Casimir scaling in the source used
   (else the tension ratio input is wrong); finite-T sources carry a
   temperature caveat; and the derived 3/2 assumes the adjoint tube is a
   strand bundle of the same medium -- the one-medium commitment again,
   which is what makes this a test of the SAME ontology RHO tested, on an
   orthogonal axis (color charge instead of quark mass).
