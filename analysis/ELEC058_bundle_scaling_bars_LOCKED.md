# ELEC-058 — Does the bundle escape survive at small strand scale? Locked bars

## Commission
ELEC-057 found the electron and hbar sectors mutually exclusive across the
whole allowed range of the one free length a. The proposed escape: take the
SMALL (electron-viable) a and recover the large effective tension the hbar
sector needs by BUNDLING many strands, since T_eff = N T0 and T0 ~ a^2.
Geometry permits it -- at a = 4.73e-21 the required N = 2.0e10 bundle is only
0.22 fm across, comfortably inside a nucleus. The two claims that previously
killed the collective number (ELEC-043 causality, ELEC-047 recruitment census)
were both evaluated at a = 1e-16. This session asks whether they scale.

## The question, stated precisely
Is the recruitment shortfall SCALE-INVARIANT (a pure ratio, in which case the
escape dies at every a and ELEC-057's no-go hardens), or does it scale with a
(in which case ELEC-057's no-go is conditional on single-strand hbar and the
one-medium declaration survives)?

## Locked bars
B1 (THE SCALING OF THE CAUSAL BUDGET). Derive how ELEC-047's recruitment
   n_free = pi (c tau0/w)^2 scales with a, given tau0 ~ 1.9-2.0 w/c. Report
   whether it is invariant or scaling. NOTE THE TRAP, recorded before
   computing: ELEC-043's timescales (d_c/c, R/c, L/c) are OBJECT timescales,
   and under one medium with rigid rescaling the object shrinks with a too --
   so a naive "shrinking a raises the bound by (1e-16/a)^2" holds tau FIXED
   and is wrong if tau rescales. Determine which applies.
B2 (THE DEMAND'S SCALING). The bundle must supply T_eff = 2 pi hbar c /
   L_target^2 with L_target set by NUCLEAR size -- a scale fixed by QCD that
   does NOT rescale with a. Compute the required coherence radius
   R_c = w sqrt(N) as a function of a and report its scaling. A demand fixed
   in metres against a budget that shrinks with a is the decisive asymmetry
   if it appears.
B3 (THE VERDICT). Compute the shortfall ratio R_c / (c tau0) across the
   allowed range of a. ESCAPE SURVIVES if the ratio reaches 1 anywhere inside
   the Lorentz bound; ESCAPE DIES if it does not, and DIES WORSE AT SMALL a if
   the ratio grows as a shrinks.
B4 (THE WHOLE-TUBE VARIANT). The strongest form of the proposal: let the
   hbar-carrying object be the entire flux tube, T_eff = T_tube = 1.878e5 J/m,
   which is MEASURED and a-independent, giving L = 1.03 fm and satisfying the
   nuclear gate at any a. Test it against the same causal budget. If the
   geometry is free but the recruitment is not, say so explicitly -- this is
   ELEC-047's finding restated and must not be presented as new.
B5 (CONSEQUENCE FOR ELEC-057). State whether ELEC-057's no-go is hardened
   (escape dies) or narrowed to conditional (escape lives). No softening of
   either outcome.
