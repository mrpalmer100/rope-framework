core existence at the coarse level (registered: c4 = (k - T0)/8 > 0,

The floor is therefore of the convicted family, exactly as the flag

1. THE MAPPED FLOOR: the SAME coarse condition (k/T0 > 1) through the
   ADOPTED dynamical mapping. This leg is closed-form arithmetic on

   BLOCH-L affine leg, so the mapped floor does NOT inherit the
   FND-114 k/T0 = 2 adjudication rider (the condition is an
   inequality in k/T0, not an evaluation at 2). State this.

2. THE DIRECT QUARTIC LEG: the coarse-effective quartic coefficient
   of the wound medium computed from the exact ensemble at quartic
   order in the applied uniaxial strain -- the analogue, one order up,
   of the affine harmonic leg the dynamical mapping came from.
   Fibre energy per unit reference arc T(lambda - 1) +
   (k_f/2)(lambda - 1)^2, lambda = |(I + gamma e x e) t|, expanded
   exactly; ensemble moments E[(t.e)^2n] for n = 1..4 computed
   numerically over the two-level ensemble. MEASURE SENSITIVITY is
   declared up front: the quartic coefficient, unlike the harmonic
   one, depends on the strain measure and on the constitutive
   measure, so this leg CHARACTERIZES (sign, magnitude, anisotropy,
   moment content) and does not by itself adjudicate the floor.
   The floor is adjudicated by leg 1, which uses the same condition
   EM-RECON-032 used.
