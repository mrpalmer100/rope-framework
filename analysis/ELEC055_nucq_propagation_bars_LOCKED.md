# ELEC-055 — Propagating L >= pi A through NUCQ-001: locked bars (before computation)

## Commission
ELEC-054 derived a subluminality bound: the coherent segment carrying one hbar
must satisfy L >= pi A_hbar, since v_max = A omega = A pi c / L. NUCQ-001's
falsification of the mesoscopic-hbar picture was computed with L_hbar =
sqrt(hbar c/T) = 4.31 fm. The question posed: does the refutation's MARGIN
change, or only its direction?

## What must be tested (fixed before computing)
NUCQ-001 carries TWO amendments that must each be re-evaluated, not just its
headline:
- NUCQ-003 RESTORED it to unconditional (n has a floor, so L only rises).
- NUCQ-002 AMENDED it to conditional: at small STRUCTURAL n_t the patch counts
  rise and "the Born falsification DISSOLVES", so the claim refutes n_t = 111
  rather than the picture. THIS ESCAPE IS THE REAL TARGET: the bound changes
  L's dependence on n, so the escape must be re-priced.

## Locked bars
B1 (the corrected length). L_min = pi A_hbar = sqrt(2 pi hbar c / T0), at both
   registered scale sets. Report against the 4.31 fm NUCQ-001 used.
B2 (Test 2 re-run). Patch counts (R/L_min)^3 with R = 1.2 A^(1/3) fm across
   the same nuclei NUCQ-001 tabulated (He-4, C-12, O-16, Fe-56, Pb-208,
   U-238). Report the change in count and state whether the verdict's MARGIN
   moves, quantitatively.
B3 (Test 1 re-run). The tension that would place the quantum scale at the
   Yukawa range 1.4 fm is now T = 2 pi hbar c / L^2. Report the factor against
   the registered 1.70e3 and against NUCQ-001's quoted factor of 9.5.
B4 (THE ESCAPE, re-priced -- the decisive bar). Under L_min = sqrt(2 pi hbar c
   n / T_tube), patch count scales as n^(-3/2). Solve for the structural n that
   would restore Born exactness in the LIGHTEST nucleus (He-4), demanding a
   defensible threshold of >= 100 patches, and check it against the physical
   floor n >= 1 and NUCQ-003's lattice floor n >= 115. If the required n is
   unphysical, NUCQ-002's escape is CLOSED and NUCQ-001 returns to
   unconditional -- a status change that must be filed on both claims.
B5 (honesty). The bound is necessary, not sufficient: L could be larger still,
   which only worsens the counts. State the direction of every residual
   freedom, and state plainly that this session strengthens a refutation of
   the framework's own distinctive prediction.
