# ELEC-064 — Auditing the remaining T1 predictions: locked bars

## Commission
PRED-002 looked distinctive until someone read the competing model's own paper,
and it was demoted T1 -> T3. The remaining T1 entries have never had their
discrimination claims checked the same way. This audit applies the same
treatment before an outside reader does.

## The test each entry must pass (ELEC-062's criteria, unchanged)
T1 requires: quantitative; DISTINCTIVE IN OBSERVABLE OUTCOME against what
standard physics actually predicts; checkable in principle by an existing or
near-term instrument; live.

## Additional check added after PRED-002 (locked here, applied to all)
D1 DEPENDENCY HYGIENE: does the entry's derivation chain pass through a claim
   RETIRED by ELEC-061? ELEC-061's classification pass was mechanical and may
   have erred; any error found must be corrected against ELEC-061 itself.
D2 THE CONDITIONAL-POPULATION TEST: a prediction about objects whose existence
   is not established is not checkable in the required sense. State the
   conditionality explicitly.
D3 THE UNBUILT-MODEL TEST: a prediction whose discriminating branch requires a
   model the corpus has NOT built is a specification, not a prediction.
