# GRV-054 — What the gravity sector actually has: a state audit. Locked bars

## Why this claim exists
An assessment offered to the operator today stated that the sector "can only
explain weak field", that the weak-field metric is "matched, not derived", and
that four things were missing before strong field could be attempted. Running
tools/forward_check.py on GRV-001 and GRV-005 -- the claims that assessment
relied on -- immediately surfaced later claims that contradict it. THE
ASSESSMENT WAS BUILT ON SUPERSEDED CLAIMS. This audit replaces it with the
sector's actual state, and is registered rather than delivered in conversation
because a wrong assessment that shaped a research decision should be on the
record.
