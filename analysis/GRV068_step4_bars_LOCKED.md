# GRV-068 — Step 4: diagonalise the linear Cosserat operator. Locked bars

## Commission
GRV-065 registered four steps that would make the gravitomagnetic route
rigorous, with the fourth decisive: diagonalise the coupled static operator in
Fourier space and show every source-coupled metric-vector mode carries a
massless k^2 rather than k^2 + ell^-2. Steps 1-3 were addressed by GRV-066 and
GRV-067. This is step 4.

## The operator, fixed before computing
Most general quadratic isotropic parity-even vector sector in (u, phi):
   (T/2)|k u|^2 + (gamma/2)|k phi|^2 + (kappa/2)|phi - (i k x u)/2|^2
GRV-067 forces kappa = 0 by Goldstone's theorem. Both the kappa = 0 case and the
general-kappa case must be reported, so the result does not depend on that claim
alone.

## Locked bars
B1 Diagonalise at kappa = 0. Report every eigenvalue and whether any carries a
   constant (mass) term.
B2 Diagonalise at GENERAL kappa, and evaluate at k = 0. If a massless mode
   survives for arbitrary kappa, say so -- that would make the conclusion
   independent of GRV-067.
B3 IDENTIFY WHICH MODE THE SOURCE COUPLES TO. A mass in a mode that angular
   momentum does not excite is irrelevant. Give the massless eigenvector and
   state what it represents.
B4 THE VERDICT on GRV-065's step 4, and what remains of GRV-064's screening
   argument.
B5 HONEST LIMITS: what this diagonalisation does and does not establish.
