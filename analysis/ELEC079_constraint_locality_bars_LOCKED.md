# ELEC-079 — Is strand conservation local or global? Locked bars

## Commission
ELEC-078 reconciled EM-RECON-011's legs by reading u' as the strand density
perturbation, then imposed strand-number conservation as the LOCAL constraint
integral u' dx = 0 and found the attraction vanishes -- a third model with no
soliton. It named the deciding question: does that conservation hold locally in
a deformed region?

## The distinction to be drawn, fixed before deciding
Two different quantities could be meant by "strand conservation" and they impose
different constraints:
  (a) CROSSING NUMBER -- strands crossing a plane. Curves cannot end, so this is
      a topological invariant.
  (b) TOTAL STRAND LENGTH -- conserved for an inextensible medium.
These are not the same, and the constraint each imposes must be worked out
separately rather than assumed identical.

## Locked bars
B1 CROSSING NUMBER: does a transverse displacement change it? Report what
   constraint, if any, it places on u'.
B2 TOTAL LENGTH: is it conserved LOCALLY (between two fixed planes) or only
   GLOBALLY? A strand that can slide supplies length from elsewhere.
B3 THE VERDICT for a localised disturbance in an infinite pre-tensioned medium,
   and which of the three registered functionals it selects.
B4 CONSEQUENCE for ELEC-078's third model and for ELEC-074/075.
B5 HONESTY: state what physical assumption the verdict rests on, and what would
   overturn it.
