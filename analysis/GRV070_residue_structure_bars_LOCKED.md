# GRV-070 — The residue structure, corrected and written as one equation. Locked bars

## Commission
A reviewer approved GRV-069's revised framing and asked for two refinements plus
a rename. Both refinements are corrections to statements of mine.

## The corrections owed
R1 "SOURCES NOTHING WHATEVER" IS TOO STRONG. On the line a = -b a rigidly
   co-rotating configuration does not source THIS ROTATIONAL CHANNEL. It could
   still source scalar gravity, compression, ordinary displacement, parity-odd
   channels or other vector fields. The intended point is valid; the wording
   invites an unnecessary objection.
R2 THE METRIC RESIDUE HAS THE SAME STRUCTURE AS THE SOURCE RESIDUE, and I
   described it wrongly. For a general linear observable map
   g_0i = c Omega_i + d phi_i, the massless-mode residue is proportional to
   (c + d) and vanishes on c = -d -- meaning THE METRIC SEES ONLY RELATIVE
   ROTATION. That is a different and weaker condition than "the metric map
   ignores microrotation entirely", which is what GRV-069 said.

## The caution that must be carried
"Measure-zero in coefficient space" does NOT mean "unlikely in a derived
theory". Physical theories often land on special lines because of symmetry,
gauge invariance, conservation laws, objectivity, parity, action-reaction, or
how matter and geometry are defined. The action could force one of these
cancellations exactly.

## Locked bars
B1 Execute R1 and R2.
B2 Write the residue in the parallel form R_0 ~ (a + b)(c + d).
B3 Write the full long-range response and the comparison with GR as ONE
   equation, so the remaining derivation is a single explicit target.
B4 Restate the claim under the reviewer's name and status.
B5 State what the next session must produce -- OR show the action lacks the
   structure to determine it, which is an equally admissible outcome.
