# ELEC-050 — The T0 question: locked bars (before computation)

## Commission
ELEC-049 filed a "4% lattice-floor tension" in T0 (registered 1.70e3 at n = 111
vs the NUCQ-003 floor n >= 115 giving T0 <= 1633). This session resolves it:
adopt the ceiling, defend n = 111, or discover the question was mis-posed.

## Pre-trace insight (recorded before bars, governing their design)
NUCQ-002's two routes -- T0 = T_tube/n (with n = 3 pi (R/a)^2 from NUCQ-003)
and T0 = Sigma a^2/3 -- are ALGEBRAICALLY EQUIVALENT iff Sigma = T_tube/(pi R^2),
i.e. iff the vacuum tension density equals the flux tube's internal density,
which is exactly the one-medium declaration (ELEC-038) applied to the tube.
If that holds, the "4%" is not a tension between derivations: it is the
residual between the framework's PREDICTED tube width and the lattice band.

## Locked bars
B1 (the equivalence). Verify symbolically-numerically: route1 = route2 iff
   Sigma = T_tube/(pi R^2). Confirm at registered numbers and report the
   residual (expected ~4%). PASS if the identity holds to arithmetic precision
   when Sigma is set to T_tube/(pi R^2).

B2 (the band, propagated). The lattice flux-tube width is 0.35-0.5 fm, not a
   point. Tabulate across R = 0.35, 0.40, 0.45, 0.50 fm: n, T0, w, and the
   HBAR chain's L_hbar = sqrt(hbar c/T0) and A_hbar = sqrt(2 hbar c/(pi T0)).
   Report the full spreads. The "4%" framing must be corrected if the true
   band exceeds it (expected: T0 spans ~2.1x).

B3 (the prediction). R_pred = sqrt(T_tube/(pi Sigma)) computed; verdict on
   consistency with the lattice band (expected: low-edge only, ~0.342 vs
   0.35-0.5). State the discriminating power: an improved lattice width
   determination EXCLUDING ~0.35 fm would force Sigma or a to move and shift
   the entire scale chain -- a named, external, feasible test.

B4 (registration decision). Based on B1-B3, decide and file: either T0 keeps
   its point value with a mandatory band caveat, or the band replaces the
   point. Annotations on NUCQ-002/003 as needed. No silent changes.

B5 (honesty). Whichever way B4 falls, the output states that the ELEC-049
   "4%" was the corner view of a band, and quotes the band wherever T0 is
   quoted henceforth.
