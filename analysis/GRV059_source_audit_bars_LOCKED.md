# GRV-059 — The source-and-form audit: does anything in the action carry a mass current? Locked bars

## Commission and a correction owed
An external reviewer sharpened GRV-058's diagnosis and corrected two things.

CORRECTION 1, the physics. The failure is NOT that the source is "unchanging".
It is that the model's gravitational response couples to CHANGING density or
deformation, while frame dragging is sourced by a STEADY MASS CURRENT. In GR a
stationary rotating body has time-independent density AND time-independent
exterior geometry AND nonzero momentum density T_0i; the resulting
gravitomagnetic field is itself stationary. A steady electric current makes a
static magnetic field; a steady mass current makes stationary frame dragging.
So the framework does not need a time-varying source. It needs a coupling to
J_m = rho v, which is a different object.

CORRECTION 2, the arithmetic. GRV-058 and the plain-language summary said zero
was excluded "twenty times over". The robust, instrument-specific number is
Gravity Probe B: 37.2 +/- 7.2 mas/yr against a GR value of -39.2, so zero
differs from the central value by 5.2 sigma. The LARES/LAGEOS mu = 1.00 +/- 0.05
is a fractional agreement whose 0.05 is dominated by a gravity-model systematic,
not a Gaussian sigma, and should be quoted as few-percent agreement rather than
converted to a sigma count.

## The audit, in the reviewer's five steps
S1 Search the existing action for any term linear in velocity, momentum density,
   vorticity, or angular momentum.
S2 If found, derive its weak-field response WITHOUT assuming the GR form.
S3 Check whether it yields a STATIONARY vector field for constant rotation.
S4 Compare tensor structure and radial dependence with A_g ~ (J x r)/r^3.
S5 Only if the correct structure appears, compute the coefficient.

## Locked bars
B1 Run S1 against the registered gravitational source and report what is there.
B2 If S1 returns nothing, the reviewer's stated conclusion applies and must be
   registered without softening: the present gravity sector is experimentally
   falsified by frame dragging, and recovery requires a coupling not currently
   in the framework.
B3 Report the corrected exclusion arithmetic.
B4 Distinguish gravitoelectric from gravitomagnetic explicitly, since that is
   the diagnosis: g_00 versus g_0i.
B5 State what a successor mechanism would have to reproduce -- all six items --
   so that no future patch can be accepted on partial agreement.
