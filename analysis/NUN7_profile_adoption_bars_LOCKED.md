## QUESTION
Does the published lattice literature contain an admissible
measurement of the SU(3) flux-tube TRANSVERSE PROFILE (the shape, not
just the width ELEC-050 already confronts), and if so, what functional
form and parameters does the corpus register as the external
chromo-profile object?

## ADMISSIBILITY, fixed at lock (B1)
A source is admissible iff ALL of:
- published lattice QCD measurement (peer-reviewed or established
  lattice-collaboration preprint with quoted uncertainties);
- measures the transverse chromoelectric (or action/energy density)
  profile of the confining tube between a static pair, as a function
  of transverse distance -- a SHAPE, with either tabulated points or
  a fitted functional form with quoted parameters;
- quark-antiquark separation in the tube-formed regime (the same
  intermediate-distance class ELEC-050's width confrontation used);
- SU(3) (SU(N) generalizations recorded as supplementary if present,
  not required).

## REPRESENTATION RULE (B2)
Whatever is adopted is registered as EXTERNAL-ADOPTED: a lattice
measurement the corpus stores, not a rope prediction and not a rope
derivation. No identification of the profile with any strand-level
object is made this session. The FND-066 name discipline applies: this
is the FLUX-TUBE-PROFILE object, cross-sector named, distinct from the
strand diameter w and from ELEC-050's width number (which it must be
CONSISTENT with, see B4).

## SELECTION RULE, fixed before search (B3)
If multiple admissible sources exist, preference order, pre-committed:
(1) largest lattice / finest spacing with continuum discussion;
(2) explicit fitted functional form over raw points alone;
(3) most recent among ties. Conflicting admissible sources at
comparable quality: register the CONFLICT, adopt nothing silently.

## CONSISTENCY GATE (B4)
The adopted profile's width measure must be compatible with the
lattice band ELEC-050 already confronted. If the adopted source
implies a width outside that band's family, the discrepancy is
registered on the face, not smoothed.

- CONFLICTED: two or more comparable sources disagree in shape class;
