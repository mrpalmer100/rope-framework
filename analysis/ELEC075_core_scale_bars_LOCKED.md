# ELEC-075 — Is the hard core physical or the continuum failing? Locked bars

## Commission
ELEC-074 found the exact solution is hollow with a hard core at r0 = 0.7642
Delta, and named the deciding test: compare r0 with the strand spacing w. If r0
lands at or below w the core is the continuum failing and the treatment is
invalid there; if r0 sits well above w the core is real structure.

## The two directions, both required
The relations are r0 = 0.7642 Delta and E = 4.3136 T0 Delta^3, with nothing in
the model fixing Delta. So the corpus's own numbers can be imposed EITHER as a
size constraint OR as a mass constraint, and BOTH must be reported:
  (a) impose ELEC-036's conservative structure bound r0 <= 1e-3 fm, read off E,
      and compare with m_e c^2;
  (b) impose E = m_e c^2, read off r0, and compare with the bound and with w.
A model that cannot satisfy both at once fails, and the size of the failure is
the result.

## Inputs, fixed before computing
w = 5.774e-17 m (ELEC-053); T0 = 1700 J/m (Sigma-route) and 1203 J/m
(lattice-anchored), both registered; m_e c^2 = 8.1871e-14 J; r_bound = 1e-3 fm.

## Locked bars
B1 Direction (a): the mass implied by the size bound.
B2 Direction (b): the size implied by the electron mass.
B3 THE CONTINUUM VERDICT: r0/w under (a). Below 1 means the core sits inside
   one strand spacing and the continuum treatment does not apply there.
B4 THE COMBINED VERDICT, stated without softening. If the two directions are
   incompatible by many orders, say so and say by how many.
B5 Report the result for BOTH registered T0 values, since the scale-chain fork
   (ELEC-053) is unresolved.
